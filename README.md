# SkyVault – Multi-Account AWS Landing Zone

## Overview
Designed and implemented a scalable multi-account AWS landing zone using AWS Control Tower and custom automation to enforce security guardrails, centralized logging, and compliance policies across hundreds of accounts.

## Features
- Automated account provisioning with AWS Control Tower and Service Catalog
- Custom SCPs (Service Control Policies) and IAM roles enforcing least privilege
- Centralized logging via AWS CloudTrail and Amazon S3
- Continuous compliance monitoring with AWS Config and Security Hub
- Cross-account access using secure role assumptions

## Technologies
- AWS Control Tower
- AWS Organizations
- IAM / SCPs
- AWS Lambda
- AWS CloudTrail
- AWS Config
- AWS Security Hub
- Amazon S3

## Impact
- Improved security posture across multi-account environments
- Reduced manual account setup time through automation
- Enabled real-time detection of policy violations
- Strengthened compliance and governance at scale
